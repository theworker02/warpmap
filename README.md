# warpmap

Warp encode/decode helpers for map payloads in pipelines.

**Site:** https://theworker02.github.io/warpmap/

## Install / run

```bash
git clone https://github.com/theworker02/warpmap.git
cd warpmap
node src/cli.js
node --test
```
